# UI reference audit

Inspected all nine original PNGs in `../../targetUI` before writing UI. Originals remain unchanged. Each reference is 390 × 844 pixels.

## Shared visual language

Background approximately #F6F3FC; navy #171337; violet #7132F5; pale violet #EEE6FF; text #24212D; muted #827C90. Cards are white, generally without shadows, with 18–20px corners. Thin lavender outlines distinguish inputs and selected documents. Use 20px page gutters, 10–12px card gaps, 16px internal padding. Inputs are about 50px tall with 14px corners. Primary buttons are violet with white semibold labels. Secondary buttons use pale violet or white. Main headings use a bold serif face (Georgia on web, serif fallback); body uses a compact sans-serif face. Outline icons, 20–24px, are violet or muted gray. Touch targets at least 44px. Bottom navigation is white, 80px including safe area, with five equally spaced destinations; active icon and label violet. Desktop retains this vocabulary in a centered wider layout.

Implement as an in-app notification presentation with explicit push-preview labeling; external push is deferred. Support read state and safe internal deep links.
